# 🏃 줄넘기 판정기

카메라(태블릿·노트북·휴대폰)로 줄넘기를 뛰는 모습을 보고 횟수를 세는 웹 판정기입니다. 줄넘기 기록 관리와 연동해 센 횟수를 학교 시트에 바로 기록할 수 있어요.

- 주소: https://musicalpe.github.io/jump-rope-checker/
- 영상은 기기 안에서만 처리되고 어디에도 저장·전송되지 않습니다. (연동할 때는 센 횟수만 학교 시트로 보냅니다)

Made by 음악적체육인

## 사용 조건

이 프로그램과 사용설명서의 저작권은 **음악적체육인**에게 있습니다. 자세한 내용은 [LICENSE](LICENSE) 파일을 봐 주세요.

| 이렇게 쓸 수 있어요 (무료) | 이렇게는 쓸 수 없어요 |
|---|---|
| 학교·교사·학생·교육기관이 교육 목적으로 사용 | 프로그램이나 그 일부를 판매하거나 유료 서비스·연수·자료에 넣기 |
| 자기 학교(학급)에 설치하고 학교에 맞게 고쳐 쓰기 | 광고를 붙여 배포·운영하기 |
| 출처를 밝히고 돈을 받지 않고 다른 선생님과 나누기 | 저작자 표시·사용 조건을 지우거나 자기가 만든 것처럼 배포하기 |

- 학생 명단과 기록은 각 학교의 구글 스프레드시트(드라이브)에만 저장되는 그 학교의 자료입니다.
- 있는 그대로 제공되며, 쓰다가 생긴 문제에 대해 저작자는 책임지지 않습니다.
- 위와 다르게 쓰고 싶으면 인디스쿨 글 댓글이나 이 저장소로 먼저 물어봐 주세요.
